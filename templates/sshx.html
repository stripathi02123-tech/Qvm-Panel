How it works

SSHX creates a secure, end-to-end encrypted SSH session accessible via web browser. After installation, you'll get a unique https://sshx.io/s/... link that anyone can open to get shell access. The session runs inside your container and can be revoked anytime.

Security tip: Only share the link with trusted people. Anyone with the link can access the terminal.
