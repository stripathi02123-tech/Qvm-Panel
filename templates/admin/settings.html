Google Authentication

Allow users to log in and register with Google
Get this from Google Cloud Console
Keep this secret! Never share it publicly
Must match the redirect URI in Google Cloud Console
Automatically create accounts for new Google users

Setup Instructions:

  1. Go to Google Cloud Console
  2. Create a new project or select an existing one
  3. Go to APIs & Services → Credentials
  4. Create an OAuth 2.0 Client ID (Web Application type)
  5. Add your Redirect URI (e.g., http://your-domain.com/auth/google/callback)
  6. Copy Client ID and Client Secret and paste them above
  7. Enable the Google+ API in your project
  8. Save changes

Bot Commands:

  • !deploy — Deploy a new VPS interactively
  • !status — View all VPS and node status
  • !users — List registered users
  • !start <vps_id> — Start a VPS
  • !stop <vps_id> — Stop a VPS
  • !restart <vps_id> — Restart a VPS
  • !delete <vps_id> — Delete a VPS
  • !nodes — View node status
  • !help — Show all commands
